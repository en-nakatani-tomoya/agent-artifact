# tech_knowledge

単発の技術ナレッジを 1 ファイル 1 トピックでスナップショット保存する場所。

## 命名規則

- ファイル名: `YYYY-MM-DD_snake_case_title.md`
- 日付は保存日（「いつ得た知見か」を表すためのもので、対象事象の発生日ではない）
- タイトルは英語スネークケース、内容が一目で分かる具体名にする

## ファイルテンプレート

```markdown
# [タイトル]

## 概要
1〜2 文で「何の話か」

## 詳細
背景・挙動・落とし穴・判断基準などの本文

## コード例
（任意）

## 参考
- リンク
```

## 想定するユースケース

- API・サービス仕様の調査メモ
- 言語機能・ライブラリ挙動の確認
- インフラ設定のハマりどころ
- 設計パターンの判断記録

## 追加のしかた

テンプレートに沿ったファイルを置いて `git add / commit / push` するだけでよい。

規約に沿ったファイル生成・コミットを一括で行うヘルパースクリプトがリポジトリ外（個人環境）に
用意されている場合はそれを使ってもよいが、必須ではない。

## 運用上の注意

- 機密情報（社名・個人名・トークン等）が含まれていないか、保存前に必ず確認する
