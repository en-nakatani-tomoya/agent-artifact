# マスクの「アルゴリズム」五戒

このアルゴリズムには、五つの戒めがある。

**第一戒――あらゆる要求事項を疑え。**  
すべての要求事項には、それを出した個人の名前をひもづけること。「法務部の要求」「安全部門の指示」といった、部門名だけの要求を受け入れてはならない。実際にその要求を決めた人間の名前を確認せよ。そして、その要求そのものを疑え。相手がどれほど優秀であっても同じだ。むしろ、優秀な人間が出した要求ほど危ない。周囲が疑わなくなるからだ。私が出した要求であっても疑え。すべてを問い直し、要求事項を少しでも筋の通ったものにせよ。

**第二戒――部品も工程も、消せるものは徹底的に消せ。**  
あとで戻さなければならないものが出てくるかもしれない。それでいい。削ったもののうち一割以上を戻す羽目にならないなら、削り方が足りなかったということだ。

**第三戒――残ったものを、単純化し、最適化せよ。**  
ただし、これは第二戒のあとにやる。そもそも存在すべきでない部品や工程を、きれいに単純化したり、巧みに最適化したりするのは、よくある失敗である。

**第四戒――サイクルタイムを縮めよ。**  
どんな工程も、必ずもっと速くできる。だが、第一戒から第三戒までを済ませたあとでなければならない。テスラの工場で私は、あとになって消すべきだったと分かった工程を高速化するために、多くの時間を費やしてしまった。

**第五戒――自動化せよ。**  
自動化は最後に来る。ネバダとフリーモントでの最大の失敗は、最初からあらゆる工程を自動化しようとしたことだった。すべての要求事項を問い直し、不要な部品と工程を削り、不具合を洗い出しきるまでは、自動化に手を出してはならない。
