# agent-artifact

技術ナレッジ・調査ログを集約する個人アーカイブリポジトリ。
日々の業務や検証で得た知見を一箇所にまとめ、後から検索・参照できるようにすることが目的。

## 構成

| ディレクトリ | 用途 | 1トピックの形 |
|---|---|---|
| `tech_knowledge/` | 単発の技術ナレッジ（API 挙動、設計パターン、ハマりどころなど） | 1 マークダウンファイル |
| `research/` | まとまった技術調査（複数ファイルや実験コードを伴うもの） | 1 ディレクトリ |

各ディレクトリの命名規則・テンプレートは配下の README を参照。

## 使い分けの目安

- 1 ファイルで完結する知見 → `tech_knowledge/`
- 複数ファイル・実験コード・段階的な調査ログを含む → `research/`
- 迷ったら `tech_knowledge/` に書き始め、膨らんだら `research/` に昇格させる

## 追加のしかた

最低限、各ディレクトリの命名規則に沿ったファイル（またはディレクトリ）を置いて
`git add / commit / push` するだけでよい。生成元のツールは問わない。

規約に沿った保存を自動化するヘルパースクリプトをいくつか用意しているが、必須ではない。
詳細は各サブディレクトリの README を参照。

## 運用上の注意

- 機密情報（社名・個人名・トークン・APIキーなど）が含まれていないか、保存前に必ず確認する
- 個人アーカイブのため、社内秘や顧客情報は載せない
